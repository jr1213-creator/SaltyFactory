# Private Beta Feature Truth Table

Status labels:

- `REAL LIVE PATH`: browser/API path performs real provider work or real internal work and persists evidence.
- `MOCKED ONLY`: tested only with mocks and no verified runtime/provider path.
- `UI ONLY`: owner UI exists but no real backend/provider action is wired.
- `BACKEND ONLY`: backend/provider method exists, but no normal owner UI path drives it.
- `STUBBED`: implementation returns a placeholder or success-looking fallback.
- `BROKEN`: known path does not complete.
- `FUTURE`: intentionally not implemented.

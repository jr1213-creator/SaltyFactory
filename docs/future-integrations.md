# Future Integrations

The following are intentionally not implemented as live execution engines in this pass:

- Shopify customer/order sync
- Shopify live product publishing beyond existing guarded draft paths
- Printify account creation
- Public capture form embeds beyond native setup foundations
- Live email sending
- Chatwoot or other support inbox sync
- Mixpost or social publishing
- Umami/PostHog-style analytics tracking
- Crawl4AI crawling
- Cal.diy/calendar sync
- Image/video generation infrastructure
- Google Ads API
- Meta Ads API
- Pinterest API
- Google/Merchant/DNS write automation without explicit owner approval gates

Manual/export-ready records are available now for campaign planning, drafts, proof packs, asset specs, UTM links, approvals, tasks, and readiness reports.

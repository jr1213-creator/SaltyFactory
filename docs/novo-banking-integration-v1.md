# Novo Banking Integration v1

Status: read-only foundation, config-blocked for provider sync.

Implemented:
- `/studio/business/banking`
- banking status, accounts, transactions, manual transaction import, transaction classification
- Novo boundary reports direct API as not verified
- Plaid/open-banking routes return exact setup requirements when not configured

Not implemented:
- Novo scraping
- storing Novo login credentials
- transfers, payments, checks, bill pay, wires, ACH, card creation, or money movement

Future:
- Plaid link/exchange/sync when credentials and owner consent are configured.

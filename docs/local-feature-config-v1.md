# Local Feature Configuration v1

This is the local/deployment setup truth table for SaltyFactory. It reflects env/config names used by code or by the feature-readiness service. It does not include secret values.

Business owners should not edit env files. Customer-facing setup happens through:

- `/studio/onboarding`
- `/studio/onboarding/guided`
- `/studio/onboarding/quick-start`
- `/studio/onboarding/providers/*`
- `/studio/setup` owner-friendly mode

Env variables are for local development, CI, and server deployment only. They may appear in Studio only inside Advanced / Developer details.

Dangerous actions stay disabled by default:

- `LIVE_PUBLISHING_ENABLED=false`
- `SHOPIFY_ALLOW_PRODUCT_PUBLISH=false`
- `PRINTIFY_ALLOW_PUBLISH=false`
- `BANKING_LIVE_SYNC_ENABLED=false`
- `BANKING_MONEY_MOVEMENT_ENABLED=false`
- `EXTERNAL_ORDER_SUBMISSION_ENABLED=false`

Use `/studio/onboarding` or `/studio/setup` after login to see owner-facing setup actions. Use `GET /api/studio/config/feature-readiness` for redacted technical readiness from the running app.

## No Dead Config States

Every config blocker must include:

- plain-English explanation
- primary setup action
- setup guide
- validation path when applicable
- request-help path
- Advanced / Developer details disclosure
- no secret values

If the user cannot safely configure something from the browser, the blocker must say administrator setup is required and provide a help request path.

## Hugging Face Image Generation Notes

The real image provider path uses Hugging Face Inference Providers server-side only. Owner-entered tokens are write-only and, when credential storage is enabled, encrypted before being referenced by provider connection rows. Tokens are never returned to the browser or logs.

Token requirement:
- Create a fine-grained Hugging Face token.
- Enable `Make calls to Inference Providers`.
- Paste it only into the secure Studio field.

Recommended text-to-image models for the current `hf-inference` path:
- `black-forest-labs/FLUX.1-schnell`
- `stabilityai/stable-diffusion-3-medium-diffusers`

`stabilityai/stable-diffusion-xl-base-1.0` is not assumed to work with this path and returns `model_not_supported` in guided validation.

Error interpretation:
- `token_missing`: no token was pasted or saved.
- `token_invalid`: Hugging Face rejected the token.
- `permission_missing`: token lacks Inference Providers permission.
- `model_not_found`: model ID is missing or not found.
- `model_not_supported`: selected model is not supported by the current provider path.
- `model_gated`: terms/access for the model have not been accepted.
- `quota_or_billing`: billing, credits, quota, or rate limits blocked the call.
- `provider_unreachable`: network or Hugging Face reachability failure.
- `endpoint_misconfigured`: wrong router/provider path.
- `unknown_provider_error`: Hugging Face router/API failure that does not match a safer specific status.

Local demo mode is development/test-only and does not count as provider success. Production must use a real configured provider and private storage.
